# Sauna Studio

川沿いのサウナで過ごす時間を、予約から運営まで。

貸切・共用サウナ、日帰り・宿泊テントの複数商品予約、オンライン決済、利用者・スタッフのチャット、設備・在庫・シフト管理を開発しています。

Swift / SwiftUI / SvelteKit / PostgreSQL / Google Cloudを採用し、Passkey認証、Google Workspace連携、Google Chat Bot、AIエージェント向けMCP、OpenTelemetryを組み合わせます。

開発基盤・規則は [.github](https://github.com/sauna-studio/.github)、設計・ADRは [sauna-docs](https://github.com/sauna-studio/sauna-docs) を参照してください。
